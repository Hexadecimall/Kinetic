# Security Policy

Kinetic is pre-release software and does not yet provide a stable security-support window.

Do not report suspected vulnerabilities in a public issue. Use GitHub's private vulnerability
reporting feature for the `Hexadecimall/Kinetic` repository.

Native plugins execute with the user's privileges. Kinetic will distinguish trusted built-in
components from third-party plugins, display plugin provenance, and require explicit approval for
security-sensitive capabilities.
